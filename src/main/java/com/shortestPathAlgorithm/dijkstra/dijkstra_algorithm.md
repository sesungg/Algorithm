# 다익스트라 알고리즘 (Dijkstra Algorithm)

다익스트라 알고리즘은 **가중치가 음수가 없는 그래프**에서 하나의 시작점으로부터 다른 모든 정점까지의 **최단 경로**를 찾는 알고리즘입니다.  
대표적인 **그래프 탐색 기반 최단 거리 알고리즘**으로, 내비게이션이나 네트워크 라우팅에서 자주 사용됩니다.  

---

## 다익스트라 알고리즘의 작동 방식
1. 시작 정점의 거리를 0으로, 나머지 정점의 거리는 무한대로 초기화한다.  
2. 아직 방문하지 않은 정점 중에서 거리가 가장 짧은 정점을 선택한다.  
3. 해당 정점을 기준으로 연결된 다른 정점들의 거리를 확인하고,  
   **기존 거리 > (현재 정점 거리 + 간선 가중치)** 이면 갱신한다.  
4. 모든 정점이 방문될 때까지 2~3 과정을 반복한다.  

---

## 다익스트라 알고리즘 예제
그래프: (정점 0에서 시작)  

```
0 --(7)-- 1
|  \      |
9    14   15
|     \   |
2 --(11)--3
|          |
2          6
|          |
5 --(9)-- 4
```

초기 상태:
```
dist = [0, ∞, ∞, ∞, ∞, ∞]
```

1. 0번에서 시작, 이웃 거리 갱신 →  
   dist = [0, 7, 9, ∞, ∞, 14]  
2. 거리 가장 짧은 정점(1) 확정, 이웃 거리 갱신 →  
   dist = [0, 7, 9, 22, ∞, 14]  
3. 정점(2) 확정, 이웃 거리 갱신 →  
   dist = [0, 7, 9, 20, ∞, 11]  
4. 정점(5) 확정, 이웃 거리 갱신 →  
   dist = [0, 7, 9, 20, 20, 11]  
5. 정점(3) 확정, 이웃 거리 갱신 →  
   dist = [0, 7, 9, 20, 20, 11]  
6. 정점(4) 확정, 종료.  

최종 결과:  
```
0 → 0 : 거리 0
0 → 1 : 거리 7
0 → 2 : 거리 9
0 → 3 : 거리 20
0 → 4 : 거리 20
0 → 5 : 거리 11
```

---

## 다익스트라 알고리즘의 시간 복잡도
- **인접 리스트 + 우선순위 큐 사용**: O((V + E) log V)  
- **인접 행렬 사용**: O(V²)  

## 공간 복잡도
- dist 배열, 우선순위 큐, 그래프 저장용 공간 필요  
- O(V + E)  

---

## 다익스트라 알고리즘의 장점과 단점

### 장점
- 효율적으로 단일 시작점 최단경로를 구할 수 있다.  
- 우선순위 큐를 사용하면 큰 그래프에서도 빠르게 동작한다.  
- 내비게이션, 네트워크 라우팅 등 실무 활용도가 높다.  

### 단점
- **음수 가중치가 있는 그래프에서는 사용할 수 없다.** (→ 벨만-포드 알고리즘 필요)  
- 모든 정점까지의 거리를 구하므로, 특정 목적지 하나만 필요할 경우에는 비효율적일 수 있다.
